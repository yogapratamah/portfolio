Case 01 — Design Ops

Scaling B2B White-Label POS via Figma Variables Automation

Problem: Onboarding new white-label POS clients depended on manually rebuilt UI kits for every merchant theme — slow, error-prone, and hard to maintain at scale.

Solution: Migrated the system to a multi-tier token architecture in Figma Variables: primitive tokens for raw values, semantic tokens for intent, and a component layer resolving automatically per client theme.

Impact: Cut client onboarding friction dramatically and removed design bottlenecks from the sales pipeline entirely.

Case 02 — Multi-Platform SaaS

Ignatia POS: Mobile Ecosystem Architecting Portrait & Landscape

Execution: Built the foundational B2B POS multi-platform ecosystem from scratch. Designed highly adaptive native interfaces for both portrait and landscape layouts across tablets and mobile devices used in varied retail setups.

Case 03 — Data Architecture

Overhauling Legacy Dashboard for Dense Data Presentation

Execution: Structural overhaul and responsive web migration of the legacy merchant dashboard, restructuring information hierarchy to keep dense operational data legible without hiding important metrics.
